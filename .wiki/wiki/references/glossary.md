# Glossary

> Термины, используемые в интерфейсе, модели данных и бизнес-процессах.

| Термин | Описание |
|---|---|
| Филиал | Территориальное подразделение организации. |
| Лаборатория | Подразделение внутри филиала, выполняющее один или несколько видов исследований. |
| Объект | Источник образцов с названием и адресом. |
| Направление | Сопроводительный документ от санитарного врача со списком образцов, временем сбора и дедлайнами. |
| Образец | Конкретный материал, привезённый на регистрацию. |
| Проба | Часть образца, которая поступает в лаборатории на исследование. |
| Тип образца | Категория образца, например вода питьевая, смыв, продукт питания. |
| Цель исследования | Программа проверки образца в конкретной лаборатории. Один образец может иметь несколько целей исследования. |
| Показатель | Конкретный параметр, измеряемый для типа образца и цели исследования. |
| Норма показателя | Допустимое значение показателя для сравнения с результатом. Может изменяться доктором во время исследования. |
| Испытание | Измерение одного показателя в рамках исследования пробы. |
| Исследование | Совокупность испытаний по определённой цели исследования. |
| Результат исследования | Итоговый вывод по совокупности испытаний в одной лаборатории. |
| Протокол | Итоговый документ, объединяющий образцы с заключением. |
| Заключение | Текстовый вывод для протокола, содержащий шаблонные выводы для образца или образцов. |
| Роль | Должность сотрудника, определяющая его возможности в системе. |
| Врач-лаборант | Сотрудник, который проводит испытания в лаборатории. |
| Лаборант | Сотрудник лаборатории, который просматривает образцы, направления, исследования и испытания своей лаборатории. |
| Санитарный врач | Сотрудник, который собирает образцы на объекте и доставляет их в лабораторию. |
| Дедлайн | Срок, до которого образец должен быть выпущен; задаётся на этапе регистрации. |
| Начальник лаборатории | Руководитель лаборатории, который регулирует работу и может проводить испытания при отсутствии докторов. |
| Начальник филиала | Руководитель филиала, который получает критические уведомления по исследованиям и образцам. |
| Регистратор | Сотрудник, регистрирующий образцы и создающий протоколы с заключениями. |
| Администратор пользователей | Сотрудник, управляющий пользователями, ролями и правами доступа. |
