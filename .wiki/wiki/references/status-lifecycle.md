# Lifecycle Statuses

> Нормативная модель жизненного цикла для направлений, образцов, исследований и испытаний.

## Direction Statuses

| code | name | Комментарий |
|---|---|---|
| `draft` | Черновик | Направление создано вручную или импортировано без типов образцов и назначенных лабораторий. |
| `registered` | Зарегистрировано | Проставлены типы образцов и назначены лаборатории. Переход выполняет регистратор. |
| `in_progress` | В работе | Автоматически: хотя бы один образец перешёл в статус `in_progress` / «На исследовании». |
| `partially_completed` | Частично выполнено | Автоматически: хотя бы один образец закрыт, но не все. |
| `completed` | Выполнено | Автоматически: все образцы закрыты. |

### Direction Transitions

| Из | В | Инициатор |
|---|---|---|
| `—` | `draft` | Система при импорте без типов / регистратор вручную. |
| `draft` | `registered` | Регистратор после проставления типов образцов и назначения лабораторий. |
| `registered` | `in_progress` | Система, когда хотя бы один образец перешёл в `in_analysis` / рабочий статус. |
| `in_progress` | `partially_completed` | Система, когда хотя бы один образец закрыт. |
| `partially_completed` | `in_progress` | Система, когда назначены новые исследования. |
| `partially_completed` | `completed` | Система, когда все образцы закрыты. |
| `in_progress` | `completed` | Система, когда все образцы закрыты. |

## Sample Statuses

| code | name | Комментарий |
|---|---|---|
| `pending` | На регистрации | Образец создан в рамках направления и ожидает приёмки в лаборатории. |
| `registered` | Зарегистрирован | Образец принят регистратором; проставляется `received_at`, вычисляется `deadline`. |
| `rejected` | Брак | Образец признан непригодным. Все исследования автоматически отменяются. Терминальный статус. |
| `in_progress` | На исследовании | Оператор лаборатории начал работу с образцом. |
| `analyzed` | Обработан | Автоматически: все исследования по образцу завершены. |
| `completed` | Закрыт | Начальник лаборатории подтвердил, что новых исследований не будет; устанавливается `verdict`. Терминальный статус. |

### Sample Transitions

| Из | В | Инициатор |
|---|---|---|
| `—` | `pending` | Система при создании образца в рамках направления. |
| `pending` | `registered` | Регистратор. |
| `pending` | `rejected` | Регистратор или доктор в лаборатории при браке. |
| `registered` | `in_progress` | Оператор лаборатории. |
| `in_progress` | `analyzed` | Система, когда все исследования завершены. |
| `analyzed` | `in_progress` | Система, когда назначены новые исследования. |
| `analyzed` | `completed` | Начальник лаборатории. |

### Sample Cascade

- `pending -> rejected`: все исследования (`results` / `research`) образца автоматически переводятся в `rejected` с `cancellation_reason = 'sample_rejected'`.

## Research Statuses

| code | name | Комментарий |
|---|---|---|
| `draft` | Черновик | Исследование выбрано регистратором, но ещё не подтверждено доктором. |
| `ordered` | Запланировано | Подтверждено доктором или начальником лаборатории, готово к выполнению. |
| `in_progress` | В работе | Доктор приступил к выполнению. |
| `completed` | Завершено | Автоматически: все испытания по исследованию завершены; устанавливается `verdict`. |
| `rejected` | Отклонено | Отменено доктором, начальником лаборатории или автоматически при браке образца. Терминальный статус. |

### Research Transitions

| Из | В | Инициатор |
|---|---|---|
| `—` | `draft` | Регистратор выбрал исследование. |
| `—` | `ordered` | Начальник лаборатории или доктор подтвердил. |
| `draft` | `ordered` | Начальник лаборатории или доктор подтвердил. |
| `draft` | `rejected` | Начальник лаборатории, доктор или регистратор убрал исследование. |
| `ordered` | `in_progress` | Доктор. |
| `in_progress` | `completed` | Система, когда все испытания в финальном статусе. |
| `completed` | `in_progress` | Система, когда начальник лаборатории назначил новые испытания. |

## Test Statuses

| code | name | Комментарий |
|---|---|---|
| `queued` | Запланировано | Автоматически создаётся при назначении исследования. |
| `in_progress` | Выполняется | Доктор приступил к проведению испытания. |
| `completed` | Выполнено | Доктор завершил испытание и получил результаты. |
| `rejected` | Отклонено | Испытание отменено доктором, начальником лаборатории или системой. Терминальный статус. |

### Test Transitions

| Из | В | Инициатор |
|---|---|---|
| `—` | `queued` | Система при назначении исследования. |
| `queued` | `in_progress` | Доктор или начальник лаборатории. |
| `in_progress` | `queued` | Доктор или начальник лаборатории вернул испытание в очередь. |
| `in_progress` | `completed` | Доктор или начальник лаборатории внёс результат. |
| `in_progress` | `rejected` | Доктор или начальник лаборатории решил не проводить испытание. |
| `queued` | `rejected` | Доктор, начальник лаборатории или система отменили испытание. |
