# Матрица доступа по ролям

## Легенда — действия

| Обозначение | Действие                                                                 |
| ----------- | ------------------------------------------------------------------------ |
| **C**       | Create — создание                                                        |
| **R**       | Read — чтение / просмотр                                                 |
| **U**       | Update — редактирование                                                  |
| **D**       | Delete — удаление (soft)                                                 |
| **IMP**     | Import — импорт направления из файла                                     |
| **REG**     | Register — регистрация (образец / направление)                           |
| **REJ**     | Reject — отклонение / брак                                               |
| **CNF**     | Confirm — подтверждение исследования (`draft → ordered`)                 |
| **STR**     | Start — взять в работу (`ordered → in_progress`, `queued → in_progress`) |
| **RES**     | Result — внести результат испытания (`in_progress → completed`)          |
| **REQ**     | Requeue — вернуть испытание в очередь (`in_progress → queued`)           |
| **CLO**     | Close — закрыть образец, установить вердикт (`analyzed → completed`)     |
| **MRK**     | Mark as read — отметить как прочитанное                                  |
| **HID**     | Hide — скрыть уведомление                                                |
| **—**       | Нет доступа                                                              |

## Примечания по области видимости (scope)

| Метка | Описание                                                   |
| ----- | ---------------------------------------------------------- |
| $^1$  | Только по своим созданным записям                          |
| $^2$  | Только в рамках своей лаборатории                          |
| $^3$  | Только в рамках своего филиала                             |
| $^4$  | Только пока запись в статусе `draft`                       |
| $^5$  | Только для указанного идентификатора                       |
| $^6$  | Видит протоколы, в которые входит хотя бы один его образец |
| $^7$  | Только свои уведомления                                    |

> **НФ** — scope настраивается: только свой филиал или все филиалы (зависит от конфигурации `user_scopes`).
