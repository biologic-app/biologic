# Статусы направлений (direction_statuses)

| code                | name               | Комментарий                                                                                |
| ------------------- | ------------------ | ------------------------------------------------------------------------------------------ |
| draft               | Черновик           | Направление создано вручную или импортировано без типов образцов и назначенных лабораторий |
| registered          | Зарегистрировано   | Проставлены типы образцов и назначены лаборатории. Переход: Регистратор                    |
| in_progress         | В работе           | Автоматически: хотя бы один образец перешёл в статус «На исследовании»                     |
| partially_completed | Частично выполнено | Автоматически: хотя бы один образец закрыт, но не все                                      |
| completed           | Выполнено          | Автоматически: все образцы закрыты                                                         |

## Допустимые переходы статусов (direction_statuses)

| Из                  | В                   | Инициатор                                                       |
| ------------------- | ------------------- | --------------------------------------------------------------- |
| —                   | draft               | Система (импорт без типов) / Регистратор (вручную)              |
| draft               | registered          | Регистратор (проставлены типы образцов и назначены лаборатории) |
| registered          | in_progress         | Система (хотя бы один образец перешёл в `in_analysis`)          |
| in_progress         | partially_completed | Система (хотя бы один образец закрыт)                           |
| partially_completed | in_progress         | Система (назначены новые исследования)                          |
| partially_completed | completed           | Система (все образцы закрыты)                                   |
| in_progress         | completed           | Система (все образцы закрыты)                                   |

# Статусы образцов (sample_statuses)

| code        | name            | Комментарий                                                                                                                                                        |
| ----------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| pending     | На регистрации  | Образец создан в рамках направления, ожидает приёмки в лаборатории                                                                                                 |
| registered  | Зарегистрирован | Образец принят регистратором. Проставляется `received_at`, вычисляется `deadline`                                                                                  |
| rejected    | Брак            | Образец признан непригодным при приёмке доктором. Все исследования автоматически отменяются. Терминальный статус                                                   |
| in_progress | На исследовании | Оператор лаборатории начал работу с образцом                                                                                                                       |
| analyzed    | Обработан       | Автоматически: все исследования по образцу завершены                                                                                                               |
| completed   | Закрыт          | Начальник лаборатории подтвердил: новых исследований не будет. Устанавливается `verdict`. Терминальный статус. После completed любые новые исследования запрещены. |

## Допустимые переходы статусов (sample_statuses)

| Из          | В           | Инициатор                                               |
| ----------- | ----------- | ------------------------------------------------------- |
| —           | pending     | Система (создан в рамках направления)                   |
| pending     | registered  | Регистратор                                             |
| pending     | rejected    | Регистратор (брак при приёмке) или доктор в лаборатории |
| registered  | in_progress | Оператор лаборатории                                    |
| in_progress | analyzed    | Система (все исследования завершены)                    |
| analyzed    | in_progress | Система (назначены новые исследования)                  |
| analyzed    | completed   | Начальник лаборатории (подтвердил завершение)           |

## Каскадные эффекты

- `pending → rejected` → все исследования (`results`) образца автоматически переводятся в `rejected` с `cancellation_reason = 'sample_rejected'`

# Статусы исследований (research_statuses)

Исследования создаются сразу в статусе `in_progress` — при регистрации
направления они авто-назначаются по типу образца (см. Part D плана), поэтому
статусы `draft`/`ordered` и команды `research.confirm`/`research.start` удалены.

| code        | name      | Комментарий                                                                                                          |
| ----------- | --------- | -------------------------------------------------------------------------------------------------------------------- |
| in_progress | В работе  | Исследование создано и сразу в работе (авто-назначение при регистрации направления)                                 |
| completed   | Завершено | Автоматически: все испытания по исследованию завершены. Устанавливается `verdict`                                    |
| rejected    | Отклонено | Исследование отменено доктором / начальником лаборатории / либо автоматически при браке образца. Терминальный статус |

## Допустимые переходы статусов (research_statuses)

| Из          | В           | Инициатор                                            |
| ----------- | ----------- | ---------------------------------------------------- |
| —           | in_progress | Система (авто-назначение при регистрации направления) |
| in_progress | completed   | Система (все испытания в финальном статусе)          |
| in_progress | rejected    | Начальник лаборатории / доктор / регистратор / брак образца |

# Статусы испытаний (test_statuses)

Испытания создаются сразу в статусе `in_progress` вместе с исследованием,
поэтому статус `queued` и команды `tests.start`/`tests.requeue` удалены.

| code        | name        | Комментарий                                                                                                          |
| ----------- | ----------- | -------------------------------------------------------------------------------------------------------------------- |
| in_progress | Выполняется | Испытание создано вместе с исследованием и сразу в работе                                                            |
| completed   | Выполнено   | Доктор завершил испытание и получил результаты                                                                       |
| rejected    | Отклонено   | Испытание отменено доктором / начальником лаборатории / либо автоматически при браке образца. Терминальный статус    |

## Допустимые переходы статусов (test_statuses)

| Из          | В           | Инициатор                                                                                              |
| ----------- | ----------- | ------------------------------------------------------------------------------------------------------ |
| —           | in_progress | Система (создано вместе с исследованием)                                                                |
| in_progress | completed   | Доктор / Начальник лаборатории (внёс результат)                                                        |
| in_progress | rejected    | Доктор / Начальник лаборатории (по каким либо причинам было принято решение не проводить это испытание) |
